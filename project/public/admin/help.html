Owner guide

Update your website.

Start from owner tools. Choose Manage gaming PCs, Update pages & contact, or Manage repair services to open the right screen.

First sign-in

  1. Sign into the GitHub account that owns or can write to Wilson0279737/UpGPC_Codex.
  2. In GitHub, create a fine-grained personal access token. Choose only this repository, a short expiry, and Contents: Read and write. No other write permission is needed for this preview editor.
  3. Open the editor, choose Sign In Using Access Token, and paste it there. Keep the token private; do not put it in a page, PC description, screenshot, or chat.

The CMS keeps the token in this browser’s local storage to remember the session. Use a trusted computer. Sign out from the CMS account menu when finished; revoke the token in GitHub if you lose access to the computer. To recover access after expiry, create a replacement token and sign in again. GitHub handles your account password and account recovery.

Add a gaming PC

  1. Choose Gaming PC inventory → Create. Enter the real PC name and description, its specifications, and an optional price and photo.
  2. New PCs start as Draft, hidden from the catalog. Choose Available when ready. Reserved stays visible with a reserved label; Sold is hidden. A blank price displays “Call for pricing”.
  3. Save. The saved content goes to the website’s review branch. Open the review preview and check the result. A rebuild can take a minute or two.

Review before release

Saved edits update codex/cms-preview, not the live website. Use the Netlify preview linked from the CMS pull request. Check the pages on your phone too. Publishing to upgradegamingpcs.com is a separate, owner-approved release.

The CMS may call its save action “Publish”. In this setup that action only commits to the review branch. It does not release to the live website.

Photos and content

Choose a JPG, PNG, or WebP photo up to 10 MB. The editor renames and resizes new photos to keep pages fast. A photo description is optional for a PC listing; the PC name is used if it is blank. The listing preview shows the photo, price, specifications, and whether the PC will be visible.

Fields show character limits while you type. Save checks explain common PC, page, contact, and service issues before content is committed. For the embedded map, use the URL from Google Maps → Share → Embed a map; an ordinary directions link belongs in the separate directions field.

Keep private customer information and internal notes out of website content. Customer account information belongs in the sign-in service, separate from this public content repository.

Try it first

The practice editor needs no account. Its edits stay in this browser and never update the website. Reload to confirm a saved practice edit persists. Practice data and real website data are separate.

To start practice over, open the editor’s Settings → Data Management, clear the practice file cache, then start the demo again. This removes this browser’s practice edits and restores the sample content. It does not change the GitHub repository.

Customer Google sign-in

Google sign-in is available on the account test website. Owner accounts with the manually assigned admin role see an Open website editor link after their profile loads. The editor still checks separate GitHub repository permissions; use the editing key from the first sign-in steps above. Ordinary customer accounts do not gain editing permission.

  1. Use a separate Netlify test project for this branch so test accounts stay separate from the live site.
  2. In that project, enable Identity, then enable Google under its registration / external-provider settings. Netlify offers a default Google connection.
  3. Set the public build option VITE_CUSTOMER_ACCOUNTS=true for that test deployment and rebuild it.
  4. Open /account on the test website. Check real Google sign-in, sign-out, and saving/removing a PC. Sign in again in another browser to confirm the saved list follows the account.

After those checks, decide when to enable customer accounts on the live website. No live sign-in settings were changed in this preview. See the Netlify setup instructions.
