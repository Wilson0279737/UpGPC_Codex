Owner guide

Update your website.

Use Website content for the home page, about section, contact information, catalog introduction, and services. Use Gaming PC inventory to add and manage systems.

First sign-in

  1. Sign into the GitHub account that owns or can write to Wilson0279737/UpGPC_Codex.
  2. In GitHub, create a fine-grained personal access token. Choose only this repository, a short expiry, and Contents: Read and write. No other write permission is needed for this preview editor.
  3. Open the editor, choose Sign In with Token, and paste it there. Keep the token private; do not put it in a page, PC description, screenshot, or chat.

The CMS keeps the token in this browser’s local storage to remember the session. Use a trusted computer. Sign out from the CMS account menu when finished; revoke the token in GitHub if you lose access to the computer. To recover access after expiry, create a replacement token and sign in again. GitHub handles your account password and account recovery.

Add a gaming PC

  1. Choose Gaming PC inventory → Create. Enter the real PC name and description, its specifications, and an optional price and photo.
  2. New PCs start as Draft, hidden from the catalog. Choose Available when ready. Reserved stays visible with a reserved label; Sold is hidden. A blank price displays “Call for pricing”.
  3. Save. The saved content goes to the website’s review branch. Open the review preview and check the result. A rebuild can take a minute or two.

Review before release

Saved edits update codex/cms-preview, not the live website. Use the Netlify preview linked from the CMS pull request. Check the pages on your phone too. Publishing to upgradegamingpcs.com is a separate, owner-approved release.

The CMS may call its save action “Publish”. In this setup that action only commits to the review branch. It does not release to the live website.

Photos and content

Use JPG, PNG, or WebP photos, ideally less than 2 MB. Add a short description of what the photo shows. Avoid customer names, private details, credentials, and internal notes: this website’s content repository is public. A failed preview build leaves the last successful preview available; correct the reported content and save again.

Try it first

The practice editor needs no account. Its edits stay in this browser and never update the website. Reload to confirm a saved practice edit persists. Practice data and real website data are separate.
